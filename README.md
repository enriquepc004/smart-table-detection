# Smart Table Detection

A university computer vision project that detects five table-setting objects
(plate, fork, knife, glass, napkin) and flags missing items.

## Project goal
Train and compare a classical HOG + SVM baseline with two object detectors.
Evaluate detection performance, inference speed and missing-object alerts.

## Data collection
Original videos are recorded under varied lighting and backgrounds.
Video-level train/validation/test splits prevent data leakage.
Raw videos and image datasets are kept locally, not committed to GitHub.

## Status
Project setup and data collection in progress.

## Reproducibility
Installation, dataset preparation and training instructions will be added
as the project develops.
